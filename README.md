# 📚 Book Pal

**Book Pal** is a fast, clean, responsive frontend web application built with **React** that allows users to seamlessly search millions of books using the public Open Library API. 

The application is completely serverless (client-side only)

---

## ✨ Features

- **Instant Search:** Find books by title, author, or genre instantly.
- **Dynamic Content Fetching:** Interfaces directly with the Open Library API.
- **Book Cover Support:** Fetches real book imagery seamlessly via the Open Library Covers API with visual asset placeholders for rare prints.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18
- **Build Tool:** 
- **Styling:** Vanilla CSS (CSS Grid, Flexbox, & Media Queries)
- **API Integration:** Native Browser Fetch API (Asynchronous JavaScript)
- **Data Source:** [Open Library Search API](https://openlibrary.org/dev/docs/api/search)
